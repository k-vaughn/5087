# RailNetworkPattern

The rail network pattern specializes the transport network pattern to address the needs for travel of rail vehicles (e.g., trains, subways, trams). It consists of the following classes:

- [RailNetwork](classes/RailNetwork.md)
- [RailCorridor](classes/RailCorridor.md)
- [TrackLink](classes/TrackLink.md)
- [RailSection](classes/RailSection.md)
- [TrackSegment](classes/TrackSegment.md)
