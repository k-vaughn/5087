# RoadNetworkPattern

The road network pattern specializes the transport network pattern to address the needs for vehicular travel. Road networks that are primarily designed for the movement of Road vehicles should generally be defined using the Road network pattern, which is a specialization of this pattern. It consists of the following classes:

- [RoadNetwork](classes/RoadNetwork.md)
- [Road](classes/Road.md)
- [RoadLink](classes/RoadLink.md)
- [RoadSection](classes/RoadSection.md)
- [RoadSegment](classes/RoadSegment.md)
- [RoadLane](classes/RoadLane.md)
