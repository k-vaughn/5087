# Micromobility Network Pattern

The micromobility network pattern specializes the road network pattern to address the needs for the travel of micromobility vehicles. It consists of the following classes:

- [MicromobilityNetwork](classes/MicromobilityNetwork.md)
- [MicromobilityPath](classes/MicromobilityPath.md)
- [MicromobilityLink](classes/MicromobilityLink.md)
- [MicromobilityPathSection](classes/MicromobilityPathSection.md)
- [MicromobilityPathSegment](classes/MicromobilityPathSegment.md)
- [MicromobilityLane](classes/MicromobilityLane.md)
